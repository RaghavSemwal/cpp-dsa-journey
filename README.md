## 📖 About

This repo is my C++ DSA learning log — clean notes, practice problems, and working solutions, organized topic by topic in the order I actually learn them.

Not trying to be exhaustive on day one. It grows as I go, and it's built to stay easy to navigate even after 500 problems.

## 🗂️ Structure

```
0X-Topic/
├── Notes.md        → concepts, syntax, tricks, mistakes
├── Problems/        → problem statements (.md)
└── Solutions/        → C++ solutions (.cpp)
```

Every topic folder follows this exact shape — so once you understand one, you understand all of them.

## 🏷️ Naming Convention

| What | Convention | Example |
|---|---|---|
| Topic folder | `0X-Topic-Name` (zero-padded, PascalCase) | `03-Arrays`, `19-Graphs` |
| Problem file | `0X-Problem-Name.md` (numbered per topic) | `01-Maximum-Subarray.md` |
| Solution file | Same name/number as its problem, `.cpp` | `01-Maximum-Subarray.cpp` |
| Notes file | Always `Notes.md`, one per topic | `Notes.md` |

Keeping the problem and solution numbers in sync makes it trivial to find one from the other, even with hundreds of files.

## 🚀 How I Use This

1. Watch the lecture → jot key points in that topic's `Notes.md`.
2. Solve the practice problem → save the statement in `Problems/`.
3. Write a clean solution → save it in `Solutions/` with matching filename.
4. Tick off progress in the checklist above.
